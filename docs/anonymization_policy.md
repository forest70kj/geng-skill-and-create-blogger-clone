# Anonymization Policy / 匿名化政策

Public releases must remove or replace:

公开发布前，必须删除或替换：

- third-party creator names / 第三方创作者名字
- channel names / 频道名
- identifiable transcripts / 可识别来源的转录稿
- long private sample scripts / 长篇私人样本脚本
- local filesystem paths / 本地文件路径
- user identifiers / 用户标识
- API keys or tokens / API key 或 token
- project-internal generated archive names / 项目内部生成包名

Use generic labels such as:

可以使用通用标签：

- Target Creator / 目标创作者
- Creator A / 创作者 A
- Series A / 系列 A
- Protagonist A / 主角 A
- Antagonist A / 对手 A

Keep only transferable method summaries, schemas, templates, and short anonymized examples.

公开包里只保留 transferable method summaries、schemas、templates 和短匿名化示例。
