# Anonymization Policy

Public releases must remove or replace:

- third-party creator names
- channel names
- identifiable transcripts
- long private sample scripts
- local filesystem paths
- user identifiers
- API keys or tokens
- project-internal generated archive names

Use generic labels such as:

- Target Creator
- Creator A
- Series A
- Protagonist A
- Antagonist A

Keep only transferable method summaries, schemas, templates, and short anonymized examples.
