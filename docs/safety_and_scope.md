# Safety and Scope / 安全边界

This project provides writing workflow Skills.

这个项目提供的是写作 workflow Skills，不是私人语料库，也不是冒充某个创作者的工具。

It does not:

- impersonate creators / 冒充创作者
- include private transcripts / 包含私人转录稿
- bypass user review / 绕过用户审稿
- automatically publish generated text / 自动发布生成内容
- run benchmarks by default / 默认跑 benchmark
- automatically promote outputs into a golden set / 自动把输出升级成 golden sample
- guarantee that outputs match any person exactly / 保证完全像某个具体的人

Allowed focus / 允许关注的内容：

- structure / 结构
- rhythm / 节奏
- joke mechanics / 梗和段子的机制
- evidence handling / 证据和材料怎么进入正文
- revision criteria / 怎么判断要改稿
- safety review / 公开发布前的安全检查
