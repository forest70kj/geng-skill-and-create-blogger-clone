# Anonymized Case Bite / 匿名化 Case Bite

```yaml
case_id: case_001
main_complaint: The emotional payoff arrives before the relationship setup.
specific_objects:
  - relationship meter
  - special ending image
  - compressed task list
viewer_position: confused viewer who expected buildup
mechanism_candidates:
  - game-like relationship progress
  - task overload
forbidden_shortcuts:
  - generic review language
  - ungrounded slang
```

This example shows the kind of compact brief the Skill should create before drafting.

这个例子展示的是：Skill 写正文前应该先提炼出的简短 case brief。它不是完整文章，也不是私人样本。
