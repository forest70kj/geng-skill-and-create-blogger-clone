# Contributing / 贡献

Contributions are welcome.

欢迎提交贡献。

Please do not submit private transcripts, copyrighted scripts you do not own, third-party creator names without permission, API keys, local private paths, or personally identifiable information.

请不要提交私人转录稿、你不拥有版权的脚本、未经授权的第三方创作者名字、API key、本地私人路径或个人身份信息。

Use anonymized examples whenever possible.

尽量使用 anonymized examples / 匿名化示例。
