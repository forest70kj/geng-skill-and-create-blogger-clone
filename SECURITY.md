# Security / 安全

Please report accidental leaks of API keys, tokens, private paths, user identifiers, or non-anonymized creator material.

如果你发现 API keys、tokens、private paths、user identifiers 或未匿名化 creator material 被意外泄露，请报告。

Do not publish exploit details in issues.

不要在 issue 里公开 exploit details / 可被滥用的细节。
