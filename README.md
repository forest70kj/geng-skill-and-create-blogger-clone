# geng.skill + create-blogger-clone-v2

This repository contains two anonymized writing workflow Skills:

- `geng.skill`
- `create-blogger-clone-v2`

The package is designed for controlled writing workflows based on source retrieval, staged generation, user review, micro-edits, and human-read anti-AI gates.

## Included

```text
geng.skill/
create-blogger-clone-v2/
docs/
examples/
```

## Excluded

This public package excludes private transcripts, third-party creator names, channel names, proprietary sample scripts, unredacted source material, local paths, tokens, and private generated archives.

## Default Workflow

```text
source retrieval
-> case bite extraction
-> opening only
-> user review / micro edit
-> locked opening
-> body only
-> user review / micro edit
-> ending only
-> user review / micro edit
-> full draft assembly
-> final user decision
-> optional reviewable package export
```
